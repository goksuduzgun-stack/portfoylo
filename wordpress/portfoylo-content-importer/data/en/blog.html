01 · HTML

Why semantic HTML still matters

Semantic HTML uses elements to describe the purpose of content. For example, placing navigation links in <nav> and the main content in <main> helps both teammates and assistive technology understand a page.

Using heading levels in order and giving links meaningful text are small habits with a big impact. Starting with good HTML before adding visual polish leads to more resilient pages.

02 · INCLUSIVE DESIGN

A first step toward web accessibility

Accessibility is not a feature to bolt on later; it is a starting point for design. Ensuring sufficient text contrast, labelling form fields, and supporting keyboard navigation are great first steps.

Descriptive image text, respecting reduced-motion preferences, and clear error messages also improve the experience for everyone. Testing with real users helps reveal assumptions.

03 · CSS

Responsive design: thinking mobile first

A mobile-first approach designs the essentials for a narrow screen first, then adds room and layout options for larger screens. This keeps the most important content in focus on every device.

Flexible widths, CSS Grid, and Flexbox handle most layout needs. Choosing breakpoints based on comfortable content—not specific device models—makes an interface more resilient.
